## Acceptance and promotion gates

1. Execute deterministic launcher/preflight regression tests, including negative
   controls for missing arguments, incomplete checkpoints and runtime mutation.
2. Narrowly backport the sampler counter and zero-only override to isolated
   legacy source copies. Preserve old batch layout and all model/core code.
3. Freeze source commits, verify the exact archive checksum and CLI contracts,
   and submit one four-node 20B canary at a time.
4. Require full-state restore, three finite nonzero-gradient optimizer updates,
   a fresh full checkpoint, and exact saved sample count `N + updates * GBS`.
   The canary uses reduced context and batch, and does not prove full-scale
   throughput or exact production batch behavior.
5. Only after passing canaries, queue the corrected two-seat production plan
   with disjoint active/spare host slices and the historical GBS for each
   lineage. Keep initial seeds read-only and write to fixed-position forks.
6. Verify production restore/finite-step progress and durable checkpoints;
   record exact IDs, source/runtime hashes, topology and application evidence.

## Canary attempt 2 — terminal native initialization failure

PBS `8984481` finished exit 143 after 00:07:29. Staging and imports passed;
application execution lasted about 21 seconds. The earliest failure was a
native segmentation fault during `distributed.utils.set_determinism()` at
its first `torch.distributed.broadcast`, before tokenizer/dataset/model
construction or checkpoint loading. Native frames pass through
`ProcessGroupXCCL::initXCCLComm`, `ccl_comm`/`coll_init`, and SYCL queue
submission. Rank 16 was reported signal 11; remaining ranks were terminated
by launcher cleanup. The launcher's “walltime” classification of rc143 is
not the initiating cause: the one-hour allocation had not expired.

This attempt used the unchanged source/runtime and corrected
`--dataloader.train-iters=322564`, but failed before that horizon was used.
It neither validates nor disproves the horizon repair. First-attempt
`8984401` had passed this initialization boundary on a different node set.
Hardware/node-state, native runtime resolution and a native initialization
race remain hypotheses, not diagnosed causes. Preserve both logs; next
is a minimal same-runtime collective/seed-broadcast control, not another
blind full-model retry. No production job is released.
